# Noto Color Emoji 2.051 — scalable color artwork

Unmodified Google Noto COLRv1 font, pinned to release `v2.051`.
This matches the original installed Noto bitmap font’s version and artwork:
`Version 2.051;GOOG;noto-emoji:20250818:e92753bfa55fd449e427d4d325f9c8c40408c74e`.

- SHA-256: `0ae57fe58645638523ba35f388d93739d292539a9acb84df5700c81b1e1a28d2`

COLR version 1 and CPAL store vector outlines, colors and gradients; this font
contains no CBDT/CBLC bitmap strikes. The original Unicode text remains in each
object, so font shaping handles complete emoji sequences and chosen skin tones.
The display uses actual font sizes and a translation-only world layer on zoom.
