# Dream Maker icon exports

The approved Energy forms icon is installed at `src/app/icon.svg`. Next.js serves it as `/icon.svg`, which the sidebar also uses.

| File | Purpose |
| --- | --- |
| `dream-maker-icon-animated.svg` | Resolution-independent animated source; 16-second seamless loop and reduced-motion support. |
| `dream-maker-icon-static.svg` | Resolution-independent still frame. |
| `dream-maker-icon-4096.png` | Highest-resolution static raster export, 4096 × 4096. |
| `dream-maker-icon-1024.png` | Smaller static raster export, 1024 × 1024. |
| `dream-maker-icon-1024-animated.png` | Animated PNG (APNG), 1024 × 1024, 192 frames at 12 fps, seamless 16-second loop. |
| `dream-maker-icon-1024-animated.webp` | Animated WebP, 1024 × 1024, 192 frames at 12 fps, seamless 16-second loop. |

The yellow dizzy shape, blue flame, and pink heart retain the recognizable silhouettes of Noto Color Emoji, recolored for the black hole palette. The font license is in `public/emoji/noto/LICENSE`.
